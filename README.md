# 🧹 File Organizer

A handy Python script to automatically sort and organize your messy folders.  
It groups files based on their extensions into categories like Images, Documents, Videos, etc.

## 🔧 How to Use
1. Clone the repository.
2. Run the script:
   ```bash
      python organizer.py
3. Enter the path of the folder you want to organize.

📂 What it does
Detects file types based on extensions
Moves files into categorized folders
Leaves no file behind!


📌 Dependencies
No external libraries required — just os and shutil from Python standard library.
